为什么是 Yi · Why Yi

一个家族，四个工具

在美国念书有许多看不懂的系统——税法、保险、工作签证、移民排期。Yi 把每一个都拆成一个独立的小工具，免费、双语、不需要登录。你只要在需要的那一刻打开对应的那一本就好。

为留学生打造

每个工具都默认非美国公民、F-1/J-1 身份、对美国体制不熟。例子用的是「我」不是「你应该」。

不存任何数据

所有计算都在浏览器里跑。没有账号、没有 Cookie、没有分析脚本。关掉网页，数据就消失。

不是法律建议

我们解释、计算、对比、生成检查清单。重大决定请咨询持证的会计师 / 律师 / DSO。

一个人做的

用 Claude Code 一个人做出来的。如果发现错误或想要新功能，欢迎 GitHub 提 issue。

常见问题 · FAQ

常见问题

  1. 01

    为什么叫「易」？

    「易」在中文里既是「容易」，也是变化、流动的意思。这四个工具想做的就是把复杂、令人焦虑的系统变得简单一点。

  2. 02

    我必须四个都用吗？

    不必。每个工具都是独立的——按需取用。多数人在不同人生阶段会陆续用到不同的工具。

  3. 03

    这些是法律 / 税务 / 医疗建议吗？

    不是。这些工具帮你理解规则、做计算、生成检查清单。重要决定请咨询持牌专业人士（CPA、律师、医生、DSO）。

  4. 04

    我的数据会被存吗？

    不会。所有计算都在你的浏览器本地跑——没有服务器、没有账号、没有 Cookie、没有分析脚本。关掉标签页，数据就清空。

  5. 05

    为什么免费？

    因为这本来就该免费。市面上的同类工具多数是把基础信息收费打包卖给最焦虑的那群人。Yi 的目标是让你不需要付钱也能搞清楚自己的处境。

  6. 06

    这是谁做的？

    一个用 Claude Code 自己学编程的留学生。这四个工具都是我做的——这个 hub 把它们串成一个家族。
