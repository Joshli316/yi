# Yi 易

Free, bilingual hub for the four 易 utility apps for international students in the US: 税易 ShuiYi (taxes) · 保易 BaoYi (insurance) · 工易 GongYi (work auth) · 路易 LuYi (immigration). Single-scroll page that arranges them as a family — each card links out to the live sibling app.

## Tech Stack
- Vanilla JS (ES modules) + HTML, no framework, no TypeScript
- Tailwind CSS v4 via `@tailwindcss/cli` → `dist/tailwind.css`
- localStorage for language pref (`yi:lang`)
- Playwright for build-time thumbnail capture (not runtime)
- Cloudflare Pages, project name `yi`. Live at https://yi-1ot.pages.dev/ (CF auto-suffixed because yi.pages.dev was already taken)

```
├── 404.html                 # bilingual "找不到 / Page not found"
├── _headers                 # strict CSP + security headers
├── _redirects               # SPA fallback (single-page hub)
├── manifest.json            # PWA manifest
├── robots.txt
├── sitemap.xml
├── src/
│   ├── app.js               # init: i18n, render apps, attach handlers
│   ├── i18n.js              # bilingual strings + html[lang] swap
│   ├── content.js           # YI_APPS — single source of truth (4 apps)
│   ├── render.js            # builds card DOM from content.js
│   └── styles.css           # Tailwind v4 + "Clean & helpful" custom (off-white/ink/gold)
├── public/thumbs/           # 16:9 JPEGs (auto-generated by snap-thumbs)
├── scripts/
│   ├── snap-thumbs.mjs      # Playwright: 4 live screenshots
│   └── snap-og.mjs          # Playwright: builds public/og.png (1200x630)
├── dist/tailwind.css        # built CSS (committed for CF Pages)
└── package.json             # build:css, dev:css, snap, og
```

## Conventions
- **Bilingual zine for headers, swap for body**: "易 Yi" wordmark + "Yi 易" stay bilingual-stable. Body copy (FAQ, why-yi tiles, app blurbs) swaps via `data-i18n` on toggle.
- **Toggle button** shows the CURRENT language ("中" in zh, "EN" in en).
- **html[lang]** updated in `initI18n()` and on every `setLanguage()` — needed for screen readers.
- **Single source of truth**: `src/content.js` exports `YI_APPS`. Adding/removing an app = edit content.js, no HTML touch.
- **Visual identity**: off-white `#FAFAF7`, ink `#1A1A1A`, gold `#C99A2E`. Single sharp gold rule under hero anchors the soft rounded cards. The why-yi spread breaks the centered grid (the one asymmetric break).
- **No backend, no auth, no analytics, no tracking.**

## Build & Run
```bash
npm install
npm run build:css                     # one-time CSS build
python3 -m http.server 8765           # any static server (then open http://localhost:8765)
npm run snap                          # regenerate thumbnails (Playwright)
npm run og                            # regenerate OG card
```

## Deployment
```bash
npm run build:css                     # ensure dist/tailwind.css is fresh
wrangler pages deploy . --project-name=yi
```
After first push: `git remote set-head origin --auto`.

## Backlinks in the 4 sibling apps
Each sibling app (ShuiYi, BaoYi, GongYi, LuYi) has a small `← Yi 易` chip on the LEFT side of its header, above the logo. Editing locations:
- `ShuiYi/index.html` — header at line ~262
- `BaoYi/index.html` — nav at line ~510
- `GongYi/index.html` — header at line ~28
- `LuYi/src/app.ts` — header rendered in template at line ~110

## Out of scope (v1)
- Cross-app data sharing (each app stays sovereign)
- Accounts, search, dark mode (not needed for a 1-page hub)
- Embedded iframes of the four apps (defeats the point — link out instead)
